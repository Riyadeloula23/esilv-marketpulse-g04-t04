=== HELP EXCERPT ===
  -m, --max-count=NUM       stop after NUM selected lines
  -n, --line-number         print line number with output lines

=== COMMAND ===
grep -n "AAPL" data/sample/prices.csv | head -n 3

=== OUTPUT ===
2:2026-09-01,AAPL,249.20,251.50,248.00,250.00,38000000
4:2026-09-02,AAPL,250.80,252.80,249.60,251.30,39500000
6:2026-09-03,AAPL,249.60,251.30,248.40,249.80,41000000

=== EXPLANATION ===
grep -n finds AAPL and displays the original CSV line numbers.
head -n 3 keeps only the first three matching lines.
